# 報修功能檢查 Skill

## 使用時機

當任務涉及以下內容時使用本 Skill：

- 建立或修改報修單
- 修改狀態流程
- 上傳或顯示照片
- 檢查使用者權限
- 設計報修功能的測試案例

## 執行流程

1. 讀取 `software-spec.md`，列出這次任務對應的功能與限制。
2. 找出受影響的畫面、API、資料欄位與檔案處理流程。
3. 檢查正常流程、缺少資料、格式錯誤與權限不足等情境。
4. 對照完成條件，列出需要測試的案例。
5. 將結果分成「通過」、「需要修改」與「需要人工確認」。

## 輸出格式

```text
檢查結果：通過／需要修改／需要人工確認

對應規格：
- ...

受影響範圍：
- ...

測試案例：
1. 輸入：...
   預期結果：...

需要人工確認：
- ...
```

## 不可忽略的事項

- 不得省略權限、檔案格式與檔案大小檢查。
- 不得自行更改原本的狀態定義。
- 不得把「需要人工確認」的結果說成已完成。
