# 校園設備報修系統：軟體規格書節錄

## 系統目標

讓校園使用者可以建立設備報修單、上傳必要資訊，並追蹤案件處理狀態。

## 使用者

- 學生與教職員：建立報修單、查看自己的案件
- 管理人員：查看案件、分派處理人員、更新狀態
- 維修人員：查看被分派的案件並回報處理結果

## 核心功能

### FR-01 建立報修單

使用者可以填寫設備、地點、問題描述與聯絡方式。

### FR-02 上傳照片

使用者可以附加問題照片，協助管理人員判斷狀況。

### FR-03 案件狀態

案件狀態至少包含：待處理、處理中、已完成、已退回。

### FR-04 管理與回報

管理人員可以更新案件狀態，並留下處理備註。

## 限制與規則

- 必填欄位未完成時，不得建立報修單。
- 上傳檔案必須檢查格式與大小。
- 使用者只能查看自己建立的案件。
- 狀態變更必須保留原本狀態與變更時間。
- 不確定的需求不得自行新增核心功能，應先提出問題。

## 完成條件

- 成功建立有效報修單。
- 能拒絕缺少必要資料的請求。
- 能處理不支援的檔案格式與過大檔案。
- 管理人員更新狀態後，使用者能看到最新狀態。
